"—" means there's no common size at that point. Brands sometimes label in-between sizes differently, so the millimetre size is the one to trust.

Always go by millimetres

US letters and numbers, and old UK numbers, were never fully standard, and the old UK system runs backwards (a bigger number means a thinner needle). The metric size is printed on almost every modern hook and needle, so if a pattern gives a millimetre size, use that.

Steel crochet hooks are different

Tiny steel hooks for crochet thread use their own numbers, where a higher number is a smaller hook. Check the millimetre size on the handle.

Questions crafters ask

What size is an H crochet hook?

An H-8 hook is 5 mm.

What is a US size 8 knitting needle in mm?

A US 8 needle is 5 mm, the same as an old UK size 6.

What size hook for worsted yarn?

Worsted (weight 4) usually starts with a 5.5 to 6.5 mm hook (I-9 to K-10½). Check your yarn label and swatch.
